# Zsh キーバインド

この dotfiles で追加・上書きしている Zsh のキーバインドとシェルエイリアスをまとめる。
設定本体は `nix/home-manager/programs/zsh.nix` および `nix/home-manager/programs/zsh/` 配下のスニペットで管理されている。

## よく使う操作

| キー | 用途 |
|---|---|
| `Ctrl-B` | Git ブランチを fzf で選択して `git switch` |
| `Ctrl-G` | ghq / roots 管理下のプロジェクトを fzf で選んで移動 |
| `Ctrl-R` | コマンド履歴を atuin でインクリメンタル検索 |
| `Ctrl-T` | カレントディレクトリ配下のファイル・ディレクトリを fzf で選んで挿入 |
| `Alt-C` | カレントディレクトリ配下のディレクトリを fzf で選んで `cd` 移動 |
| `Ctrl-X` → `Ctrl-K` | 実行中プロセスを fzf で選んで終了 (`SIGTERM`) |
| `Tab` | 補完候補を fzf-tab で絞り込み・選択 |
| `↑` / `↓` | 入力中の文字列による前方一致で履歴を遡る / 進む |

> [!NOTE]
> `Ctrl-X` 系はプレフィックス操作。`Ctrl-X` を押して離したあと、続けて `Ctrl-K` を押す。

## vi モード

コマンドラインの編集は vi 方式を採用し、起動時は入力モード（`viins`）になる。
`Esc` でコマンドモード（`vicmd`）に入り、`i` / `a` / `I` / `A` 等で入力モードに戻る。
カーソル形状は入力モードで縦線（bar）、コマンドモードでブロック（block）に切り替わる。

| キー | 用途 |
|---|---|
| `Esc` | コマンドモードへ移行（タイムアウト待ち時間は 0.05 秒） |
| `Home` / `End` | 行頭 / 行末へ移動（両モード共通） |
| `Delete` | カーソル位置の 1 文字を削除（両モード共通） |
| `Backspace` | 直前の文字を削除（入力モード開始前の文字も削除可能） |
| `v`（コマンドモード時） | 現在の入力行を `$EDITOR`（Neovim）で編集し、保存して閉じると戻る |

> [!TIP]
> 割り当てのない特殊キーシーケンスを受信した際、先頭の `Esc` でコマンドモードに入って後続文字が vi コマンドとして誤爆するのを防ぐため、主要なキーは `viins` / `vicmd` の両モードに明示的に登録している。

## 履歴の前方一致検索 (`↑` / `↓`)

入力中の文字列をプレフィックス条件として、コマンド履歴を前方一致で遡る。

- 例: `git` と入力して `↑` を押すと、`git` で始まる履歴のみを新しい順に辿る。`↓` で逆方向へ戻る。
- 何も入力せずに押した場合は通常の履歴移動と同じ挙動になる。
- 検索後にカーソルが行末へ移動するため、そのまま引数を追加して実行できる。
- 複数行の編集中は前方一致を無効化し、通常のカーソル行移動を優先する。

> [!NOTE]
> `Ctrl-R` の atuin は全履歴のあいまい検索を行うのに対し、`↑` / `↓` は画面を切り替えずにその場で素早く直近の類似コマンドを呼び出す用途に向いている。

## fzf 連携

fzf ウィンドウは共通で「高さ 40%、下部配置（reverse）、ボーダー付き、候補が 1 件なら自動選択」のスタイルで表示される。

| キー | 用途 |
|---|---|
| 文字入力 | 候補のインクリメンタル絞り込み |
| `Up` / `Down` | 候補のカーソル移動 |
| `Enter` | 選択を確定 |
| `Esc` / `Ctrl-C` | キャンセル |

### Git ブランチ (`Ctrl-B`)

Git リポジトリ内で使用可能。ローカルおよびリモートのブランチを一覧表示し、選んだブランチへ `git switch` する。リモートブランチを選択した場合は追跡ブランチを自動作成する。Git 管理外では `Not in a Git repository` と通知される。

### ghq プロジェクト移動 (`Ctrl-G`)

`ghq list --full-path` の結果を `roots` に通して表示する。通常のリポジトリに加え、モノレポ内の個別プロジェクトルートも候補に含まれる。右側ペインには `eza --tree` によるディレクトリ構造プレビューを表示し、選択したディレクトリへ即座に `cd` 移動する。

### コマンド履歴 (`Ctrl-R`)

fzf ではなく atuin のフルスクリーン検索画面を開く。
選択したコマンドは即座に実行されずプロンプトに挿入されるため、引数を編集してから実行できる。検索中にもう一度 `Ctrl-R` を押すと、検索スコープ（グローバル・ホスト・セッション・ディレクトリ）が順次切り替わる。

### Tab 補完 (fzf-tab)

`git <Tab>` や `cd <Tab>` などで補完候補を fzf-tab のポップアップメニューから選択できる。

- 説明文付きの候補リストが表示され、`<` / `>` で候補グループを切り替えられる。
- `cd` や `pushd` の補完時には `eza` によるディレクトリ内容プレビューを表示する。
- Home Manager 適用時に補完キャッシュ（`.zcompdump` / `.zcompdump.zwc`）を無効化し、次回起動時に再生成する。

### プロセス終了 (`Ctrl-X` → `Ctrl-K`)

`ps` コマンドでプロセス一覧を表示し、選択した PID へ `SIGTERM` を送信して安全に終了させる（`SIGKILL` による強制終了ではない）。コマンドラインに文字列が入力されている場合は、それを初期クエリとして絞り込む。

## シェルエイリアス (短縮コマンド)

設定ファイルで定義されている主なエイリアス:

| エイリアス | 実行コマンド | 用途 |
|---|---|---|
| `nfu` | `nix flake update --flake ~/dotfiles` | Flake 入力の更新 |
| `nfs` | `nix flake show ~/dotfiles` | Flake 出力一覧の表示 |
| `ngc` | `nh clean user --keep 2 --no-gcroots` | ユーザー世代の即時クリーンアップ |
| `lg` | `lazygit` | Git TUI クライアント起動 |
| `vi` / `vim` | `nvim` | Neovim 起動 |
| `code` | `code-insiders` | VS Code Insiders 起動 |
| `...` | `../../` | 2階層上のディレクトリへ移動 |
| `....` | `../../../` | 3階層上のディレクトリへ移動 |
| `.....` | `../../../../` | 4階層上のディレクトリへ移動 |

## 反映と確認

Zsh の設定を変更した場合は、Home Manager を再適用してシェルを起動し直す。

```console
nix-switch
exec zsh
```

現在のキー割り当ては `bindkey` コマンドで確認できる:

```console
bindkey '^B'       # git-switch-branch-widget
bindkey '^G'       # ghq-roots-widget
bindkey '^R'       # atuin
bindkey '^X^K'     # fkill-widget
bindkey '^[[A'     # history-prefix-up
```
